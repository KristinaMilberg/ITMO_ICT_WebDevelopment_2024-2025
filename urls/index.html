    Маршруты приложения (urls.py)

    Файл urls.py содержит определения маршрутов для всех основных функций сайта, включая работу с аккаунтами, отелями, бронированиями и отзывами.

    Основные маршруты

    • '': Главная страница сайта.
      path('', index, name='index')

    Управление аккаунтом

    • login/: Вход в систему через стандартное представление Django.
    • logout/: Выход из системы, реализованный через функцию logout_view.
    • register/: Регистрация нового пользователя.
    • account/: Просмотр информации о текущем пользователе.

    Account stuff

    path('login/', auth_views.LoginView.as_view(template_name='account/login.html', success_url='/'), name='login'),
path('logout/', logout_view, name='logout'),
path('register/', RegisterView.as_view(), name='register'),
path('account/', AccountDetailsView.as_view(), name='account-details'),

    Работа с отелями

    • hotels/: Список всех отелей.
    • hotels/<int:hotel_id>/: Детальная информация об отеле, включая список комнат и отзывы.
      path('hotels/', hotel_list, name='hotel_list'),
path('hotels/<int:hotel_id>/', hotel_detail, name='hotel_detail'),

    Управление бронированиями

    • make_reservation/<int:pk>/: Бронирование комнаты через представление RoomReservationView.
    • reservations/: Список всех бронирований текущего пользователя.
    • reservations/<int:pk>/edit/: Редактирование существующего бронирования.
    • reservations/<int:pk>/delete/: Удаление бронирования.
      path('make_reservation/<int:pk>/', RoomReservationView.as_view(), name='make_reservation'),
path('reservations/', reservation_list, name='reservation_list'),
path('reservations/<int:pk>/edit/', edit_reservation, name='edit_reservation'),
path('reservations/<int:pk>/delete/', delete_reservation, name='delete_reservation'),

    Управление отзывами

    • reviews/<int:pk>/: Создание отзыва о бронировании.
    • reviews/<int:pk>/edit/: Редактирование существующего отзыва.
      path('reviews/<int:pk>/', leave_review, name='leave_review'),
path('reviews/<int:pk>/edit/', ReviewUpdateView.as_view(), name='edit_review'),

    Административная панель

    • admin/: Доступ к административной панели Django.
      path('admin/', admin.site.urls),

    Вывод по маршрутам

    Файл urls.py включает следующие основные возможности:

    • Управление пользователями (регистрация, вход, выход, просмотр профиля).
    • Просмотр списка отелей и детальной информации об отелях.
    • Полный функционал для работы с бронированиями, включая создание, редактирование и удаление.
    • Возможность добавления и редактирования отзывов.
    • Доступ к административной панели для управления данными сайта.
