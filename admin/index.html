    Настройка административной панели Django

    1. Кастомный фильтр для статуса бронирования

    Для удобства фильтрации бронирований по их статусу добавлен пользовательский фильтр ReservationStatusFilter:

    class ReservationStatusFilter(SimpleListFilter):
    title = 'Reservation Status'
    parameter_name = 'status'

    def lookups(self, request, model_admin):
        return [
            ('Pending', 'Pending'),
            ('Confirmed', 'Confirmed'),
            ('Cancelled', 'Cancelled'),
        ]

    def queryset(self, request, queryset):
        if self.value():
            return queryset.filter(status=self.value())
        return queryset

    2. Настройка админ-панели для моделей

    HotelAdmin

    Административная панель для модели отелей:

    • list_display: отображение полей имени, звёздности, владельца, адреса и описания.
    • search_fields: поиск по имени и адресу.
    • list_filter: фильтрация по количеству звёзд.
    • exclude: поле owner исключается из формы, т.к. оно автоматически заполняется текущим пользователем.
    • get_queryset: ограничение видимости отелей только для владельца.
    • save_model: автоматическое назначение текущего пользователя в качестве владельца.
      @admin.register(Hotel)
class HotelAdmin(admin.ModelAdmin):
    list_display = ('name', 'stars', 'owner', 'address', 'description')
    exclude = ('owner',)
    search_fields = ('name', 'address')
    list_filter = ('stars',)

    def get_queryset(self, request):
        return super().get_queryset(request).filter(owner=request.user)

    def save_model(self, request, obj, form, change):
        if not change:
            obj.owner = request.user
        super().save_model(request, obj, form, change)

    AmenityAdmin

    Административная панель для модели удобств:

    • list_display: отображение названия удобства.
    • search_fields: поиск по названию.
      @admin.register(Amenity)
class AmenityAdmin(admin.ModelAdmin):
    list_display = ('name',)
    search_fields = ('name',)

    RoomAdmin

    Административная панель для модели комнат:

    • list_display: отображение номера комнаты, отеля, цены за ночь, вместимости и списка удобств.
    • search_fields: поиск по номеру комнаты и названию отеля.
    • list_filter: фильтрация по отелю и вместимости.
    • get_queryset: ограничение видимости комнат только для отелей текущего пользователя.
    • get_amenities: отображение связанных удобств в читаемом виде.
      @admin.register(Room)
class RoomAdmin(admin.ModelAdmin):
    list_display = ('number', 'hotel', 'price_per_night', 'capacity', 'get_amenities')
    search_fields = ('number', 'hotel__name')
    list_filter = ('hotel', 'capacity')

    def get_queryset(self, request):
        return super().get_queryset(request).filter(hotel__owner=request.user)

    def get_amenities(self, obj):
        return ", ".join([amenity.name for amenity in obj.amenities.all()])

    get_amenities.short_description = 'Amenities'

    ReservationAdmin

    Административная панель для бронирований:

    • list_display: отображение гостя, комнаты, дат заезда/выезда, статуса, а также свойств has_passed и has_commented.
    • search_fields: поиск по имени пользователя и номеру комнаты.
    • list_filter: фильтрация по статусу и диапазону дат.

    • list_editable: возможность редактирования статуса бронирования в списке.
    • actions: добавлены действия для массового изменения статуса бронирований.
      @admin.register(Reservation)
class ReservationAdmin(admin.ModelAdmin):
    list_display = ('guest', 'room', 'check_in_date', 'check_out_date', 'status', 'has_passed', 'has_commented')
    search_fields = ('guest__username', 'room__number')
    list_filter = ('status', ('check_in_date', DateRangeFilter))
    list_editable = ('status',)

    actions = ['mark_as_confirmed', 'mark_as_cancelled']

    def mark_as_confirmed(self, request, queryset):
        queryset.update(status='Confirmed')
        self.message_user(request, "Selected reservations have been marked as Confirmed.")

    def mark_as_cancelled(self, request, queryset):
        queryset.update(status='Cancelled')
        self.message_user(request, "Selected reservations have been marked as Cancelled.")

    mark_as_confirmed.short_description = "Mark selected reservations as confirmed"
    mark_as_cancelled.short_description = "Mark selected reservations as cancelled"

    def get_queryset(self, request):
        return super().get_queryset(request).filter(room__hotel__owner=request.user)

    ReviewAdmin

    Административная панель для отзывов:

    • list_display: отображение бронирования, рейтинга и комментария.
    • search_fields: поиск по имени пользователя и номеру комнаты.
      @admin.register(Review)
class ReviewAdmin(admin.ModelAdmin):
    list_display = ('reservation', 'rating', 'comment')
    search_fields = ('reservation__guest__username', 'reservation__room__number')

    Итоговая настройка админ-панели

    • Отели можно создавать и редактировать только для текущего пользователя.
    • Удобства, комнаты и бронирования можно фильтровать, искать и редактировать.
    • Массовое управление бронированиями позволяет быстро менять их статус.
    • Отзывы удобно просматривать и фильтровать по пользователям и комнатам.
