    Описание

    База данных предназначена для хранения и управления информацией о торгах на товарно-сырьевой бирже. Она позволяет отслеживать товары, их производителей, партии, сделки, деятельность брокеров и их контор.

    Скоуп проекта: Проект симулирует взаимодействие брокеров с биржей. Они могут отслеживать товары, покупать их и отслеживать состояние заказов. Производители, товары и их цены изменяются при помощи панели администратора.

    Интересные моменты

    Брокеры - подтип пользователей. Чтобы добавить дополнительные поля, но не ограничивать схему, я использовала тэг прокси и создала дополнительную модель BrokerInfo, чтобы расширить юзера, но не менять поведения Администратора. 

        class Broker(User):

        class Meta:
            proxy = True
            verbose_name = 'Broker'
            verbose_name_plural = 'Brokers'

        def __str__(self):
            return f'{self.username} broker'

    class BrokerInfo(models.Model):
        broker = models.OneToOneField(Broker, on_delete=models.CASCADE)
        broker_company = models.ForeignKey(BrokerCompany,
                                              on_delete=models.SET_NULL,
                                              null=True,
                                              blank=True)
        monthly_fee = models.IntegerField()
        contact_number = models.CharField(max_length=20)
